# [ПРАЙМ] Концепт главной v6 — «Портал» (боковое меню)

**Статус:** шестой концепт, **новая архитектура**  
**Превью:** http://localhost:3004/v6/  
**Референс:** текущий [prime-ltd.su](https://prime-ltd.su/) + The7 `G-04` side navigation  
**Версия:** 1.3 · 2026-05-22

---

## 0. Идея

Не лендинг «сверху вниз», а **приложение-оболочка**: слева постоянная навигация (как на живом сайте ПРАЙМ), справа — прокручиваемая главная.

| v1 · v2 | v6 Портал |
|-------|-----------|
| Header сверху | **Sidebar слева 280px** |
| Меню горизонтальное | **Вертикальное + раскрытие «Услуги»** |
| Fullscreen hero | **Контентная зона**, hero-карточка |
| Разные визуальные стили | **Единый корпоративный UI** (как знакомый ПРАЙМ) |

## 1. Layout (app shell)

```
┌──────────────┬────────────────────────────────────┐
│  SIDEBAR     │  MAIN (scroll)                     │
│  Logo        │  Topbar: хлебные крошки + CTA      │
│  Nav items   │  Hero banner                       │
│  · Услуги ▾  │  Услуги 3×3                        │
│  · Кейсы     │  Достижения                        │
│  · …         │  Клиенты                           │
│  ─────────   │  Отрасли                           │
│  Телефон     │  CTA + footer                      │
│  Соцсети     │                                    │
└──────────────┴────────────────────────────────────┘
```

**Desktop:** sidebar `position: fixed`, main `margin-left: 280px`.  
**Mobile:** sidebar overlay + burger, backdrop.

## 3. Main — секции главной

1. **Topbar** — «Главная», кнопка «Оставить заявку»
2. **Hero** — заголовок + 3 KPI + CTA (без fullscreen)
3. **Услуги** — сетка 9 карточек (как на текущем сайте)
4. **Флагман SEO** — полоса «оплата по факту»
5. **Достижения** — TOP-5, TOP-100, партнёры
6. **Клиенты** — логотипы
7. **Отрасли** — 15 плиток компактно
8. **Заявка** — форма в main
